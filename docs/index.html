The audit trail

How it works, and where it stops

  • This is one layer. OWASP is explicit that no filter fully prevents prompt injection; least-privilege tools and output checks still matter.
  • A determined attacker who adapts to this classifier can get past it. The decision layer is easy to evade by wording, and I have not run an adaptive attack against it.
  • Training data is English. Recall on German examples is much lower, shown in the metrics above.
  • The model is small by design (fast on a CPU) and is trained on public datasets that are partly synthetic.
  • Attack strings on this page are the standard public-dataset style, shown for defence. None is a working exploit against a specific product.
